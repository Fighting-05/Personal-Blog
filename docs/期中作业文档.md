## 一、项目概述

### 1.1 项目名称

**个人博客系统（Personal Blog）**

### 1.2 项目简介

基于 **Vue 3 + Node.js + MySQL** 的全栈个人博客系统，支持文章发布与管理、用户认证、评论互动、标签分类、简历制作等功能。

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | Vue 3 (Composition API + script setup) |
| 构建工具 | Vite 5 |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| HTTP | Axios |
| UI 库 | Element Plus |
| 动画 | AOS, GSAP, CountUp.js, Typed.js |
| 3D | Three.js + TagCloud |
| Markdown | marked |
| 后端 | Express.js |
| 数据库 | MySQL (mysql2) |
| 认证 | JWT + express-session |
| 日志 | Winston + Morgan |

## 三、项目架构

### 3.1 目录结构

```
Personal Blog/
├── app.js                    # Express入口
├── .env                      # 环境变量
├── client/                   # Vue 3前端
│   └── src/
│       ├── main.js           # 应用入口
│       ├── App.vue           # 根组件
│       ├── router/           # 路由+守卫
│       ├── stores/           # Pinia状态
│       ├── api/              # Axios封装
│       ├── assets/           # 全局样式
│       ├── components/       # 14个可复用组件
│       └── views/            # 15个页面组件
├── controllers/              # 业务逻辑
├── models/                   # 数据模型
├── routes/                   # 路由定义
├── middleware/               # 中间件
├── database/init.js          # 建表+种子数据
└── public/uploads/           # 上传文件
```

### 3.2 数据库设计

**10张核心表**：users, posts, categories, tags, post_tags, comments, comment_likes, likes, subscribers, guestbook

**关键关联**：
- posts.author_id → users.id
- posts.category_id → categories.id
- post_tags 多对多关联
- comments.parent_id 自关联（嵌套回复）

## 四、技术亮点

### 4.1 Vue 3 核心运用

- 全部使用 `<script setup>` 语法，Composition API
- ref、reactive、computed、watch 响应式数据
- Pinia 全局状态管理（用户认证）
- Vue Router 导航守卫（登录拦截、权限控制）
- 路由懒加载 `() => import()`

### 4.2 前端特效

- **Three.js StardustScene**：500粒子星尘背景
- **TagCloud 3D球体**：可拖拽旋转标签云
- **GSAP 动画**：登录页角色入场弹性动画
- **AOS**：页面滚动渐入动画
- **CountUp.js**：统计数字滚动效果
- **Typed.js**：首页打字机标题效果
- **EyeBall 组件**：眼球鼠标追踪、眨眼动画

### 4.3 用户体验

- Markdown 渲染 + 代码行号 + 一键复制
- 文章目录导航（TOC）
- 图片灯箱预览
- 文章点赞、分享、上一篇/下一篇
- 游客评论 + 回复嵌套
- toast 消息提示
- 阅读进度条 + 回到顶部

### 4.4 简历工具

- 4套精装模板（经典/现代/极简/专业）
- 实时预览 + 头像上传
- 工作经历/项目经验动态增减、拖拽排序
- localStorage 自动保存
- window.print() 导出PDF

### 4.5 后端设计

- Express 中间件链（认证、日志、限流、校验）
- JWT + Session 双认证，bcryptjs 加密
- express-rate-limit 接口限流
- Winston + Morgan 日志记录
- MySQL 连接池 + 种子脚本（150篇文章）

## 五、运行方式

### 5.1 环境要求

- Node.js >= 18
- MySQL >= 5.7

### 5.2 安装运行

```bash
# 1. 安装后端依赖
cd "Personal Blog"
npm install

# 2. 安装前端依赖
cd client
npm install

# 3. 启动后端（自动建表+种子数据）
cd ..
node app.js

# 4. 启动前端（新终端）
cd client
npm run dev

# 5. 访问
# http://localhost:5173
```

## 六、自我评价

本项目完整实现了一个全栈博客系统的前后端功能，涵盖用户认证、文章管理、评论互动、分类标签、全文搜索等核心业务。在开发过程中深入实践了 Vue 3 Composition API、组件化开发、Pinia 状态管理、Vue Router 路由守卫等核心概念，并通过 Express + MySQL 的全栈实践加深了对前后端协作的理解。
